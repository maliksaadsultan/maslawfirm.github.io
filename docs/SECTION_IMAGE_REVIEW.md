# Section-by-section image review and brainstorming

The user requested separate judgment for every section. This register covers every main-content heading and retained disclosure on all 27 HTML pages, plus the shared shell. Each row considers an image alternative and records its own decision. It does not equate more images with better design.

## Selected direction

24 independently prompted editorial still-life assets: one for each selected section. All are imagegen outputs, not SVG substitutes. Recognizable task objects clarify the subject, with the navy/blue palette retained. No generated text, factual diagrams, rates, official records, logos, people or MAS premises. Captions identify conceptual illustrations. Duplicate audit URLs share the same image because they contain the same section.

## Shared sections

| Section | Alternatives considered | Decision |
|---|---|---|
| Header/logo | New brand art vs original square logo | Retain supplied artwork unchanged; no generated logo. |
